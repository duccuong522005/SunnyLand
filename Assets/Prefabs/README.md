# Prefabs Directory

## 📁 Cấu trúc thư mục

- **Map/** - Prefabs cho người xây Map (Platforms, Obstacles, Backgrounds)
- **Player/** - Prefabs cho Player và các biến thể
- **Enemies/** - Prefabs cho các Enemy
- **Items/** - Prefabs cho Items (Cherry, Gem, etc.)
- **Environment/** - Prefabs cho môi trường (Trees, Houses, Props)
- **UI/** - Prefabs cho UI elements

## 🎯 Quy tắc sử dụng

### ✅ NÊN:
- Tạo Prefab trước khi thêm vào Scene
- Đặt tên Prefab rõ ràng: `Platform_Grass_01.prefab`
- Sửa Prefab trong Prefab Mode (double-click Prefab)
- Commit Prefabs thường xuyên

### ❌ KHÔNG NÊN:
- Sửa trực tiếp GameObject trong Scene
- Tạo GameObject phức tạp trực tiếp trong Scene
- Override Prefab properties không cần thiết
